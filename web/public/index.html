Your AI agent keeps working at home. Answer it from your phone.

Son of Anton runs your terminal and AI coding agents (programs like Claude Code and Codex that write and fix code for you) on your own computer. Open them from any browser or your phone and carry on exactly where you left off.

What it does for you

At your desk

  • Nothing lost on reload or restart.Your tabs and their history come back after a page reload or a reboot.
  • Every agent at a glance.Each tab shows whether its agent is working, needs you, seems stuck or is done.
  • Talk instead of type.Voice commands and dictation, in five languages.

Away from your desk

  • The same shell on your phone.Scan a QR code once and keep typing in the terminal you started on your laptop. No app to install.
  • A ping when it needs you.Your phone gets a notification when an agent is waiting for an answer.
  • Chat with your agents.Reply in a chat view, by typing or speaking.
  • Your Mac's screen, on your phone.See and click your desktop when the terminal isn't enough.

If something goes wrong

  • Usage limits handled.When Claude or Codex hits its limit, the agent waits for the reset, picks up again and replays what you typed meanwhile.
  • A spare way in.If the link to your phone drops, backup links keep you connected.
  • A lock on the door.Add a pairing password, and change it to lock out a lost phone.

It stays on your computer

Your terminals, your code and your agents run on your own machine. You don't need an account.

Your phone connects straight to your computer through a private link that only your QR code opens. An optional account can help your phone find this computer again if that link changes.

Questions

What's an AI coding agent?

A program like Claude Code or Codex that reads your project, writes code and runs commands when you ask, and checks with you before the risky steps.

Do I need Claude Code or Codex?

No. Son of Anton is a full terminal on its own. If you use Claude Code or Codex in it, it recognises them and shows what each one is doing.

I'm not comfortable with a terminal. Is this for me?

Yes. The installer does the setup, and once you start an agent you can talk to it in plain language.

What if my phone can't connect?

Your agents keep running at home. Try a backup link from the same screen, or scan the QR code again.

How do I uninstall it?

Run ~/.s0a-local/uninstall.sh in Terminal. It stops the service and removes what the installer added.

The installer runs a small background service on this computer at 127.0.0.1:4010, using your user account only. Tabs and scrollback are saved to disk, so they survive restarts. Connecting from your phone uses an encrypted tunnel that the app starts for you.

Install from the source code

Clone the repository and run it yourself. For developers who want to read or change the code.

git clone https://github.com/SimonSaysGiveMeSmile/SoA-Web && cd SoA-Web
SOA_WEB_PASSWORD=hunter2 npm install && npm start
